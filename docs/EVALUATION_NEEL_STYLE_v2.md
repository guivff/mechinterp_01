## 3. Top three objections

First, position versus content. Masking removes both the early, context-free positions and the human-written problem statements; the theory (M0) says position-overlap, but the data cannot tell that from "the base cannot predict GSM8K prompts and learned a prompt prior". The existing arms partially bear on it: C·D_math_full drops from 0.55 to 0.23 under masking, consistent with a shared prompt prior, but C's unmasked Patchscope list shows digits and arrows, not problem-statement vocabulary, which M0 predicted and did not get. So this is not answerable from existing data; it needs one arm with the loss on prompt positions but scrambled or unrelated prompt content, and the write-up must say so.

Second, dose and direction of the residual gap. C_masked still has 3.5× A's ‖ΔW‖ and its raw trace is 1.4–1.9× A's, so V(A) (0.125/0.092) is now above V(C_masked) (0.049). Read literally, GRPO leaves more trace per unit weight change than masked imitation. The claim "GRPO is hard to detect by activation diffing" therefore rests on A's small ‖ΔW‖ (1.68), i.e. on training budget, not on the learning rule or even on loss placement. This can be answered from existing data by stating it plainly: at matched loss placement the RL and SFT traces are within a factor of two either way, and the 16.63–22.63× headline was masking (~10×) times dose (~2×).

Third, n = 1 and instability. C_masked is one seed, one masking pattern, one base model; A's own V varies 36% across seeds at identical ‖ΔW‖; no ablation from the fine-tuned model was run, so "not load-bearing for behaviour" is correlational. Partially answerable: the same masking effect appears independently in the D_math pair (V 0.059 masked vs 0.179 unmasked, ‖ΔW‖ equal), so there are two datasets showing the same direction, and the seed-stable SFT arms give a reference for what a seed would cost. The ablation cannot be answered; it must be listed as the experiment he would have wanted.
